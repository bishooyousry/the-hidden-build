# Vision Forge — Skills Bank (لعبة فرق للمديرين)

ملف واحد `index.html` بدون سيرفر ولا مكتبات خارجية. المزامنة الحية عن طريق ntfy.sh العام.

## النشر (GitHub Pages)
1. أنشئ repo وارفع `index.html` و `.nojekyll`.
2. Settings → Pages → Deploy from branch (main / root).
3. افتح الرابط المنشور (لا تفتح الملف من preview أو file://).

## التشغيل
- المدرب: Trainer Dashboard ← PIN `2026` (يخفي الواجهة فقط، ليس أمانًا حقيقيًا) ← يشارك الرابط.
- اللاعب: الاسم + اختيار الفريق (٨ فرق) + الكود. الكود الفارغ = جولة تدريب فردية.
- المدرب يختار **عدد الجولات** (١ أو ٢ أو ٣) من ROUND CONTROL، ثم يضغط START ROUND. الجولة تبدأ فورًا (الوضع الافتراضي بدون انتظار).
- اختياريًا: **وقت دراسة الموجّه** (٣٠/٤٥/٦٠/٩٠ ثانية) يظهر فيه المخطط للموجّه فقط قبل أن يبدأ البناء، مع عدّ تنازلي. ووقت البناء قابل للتقليل أو الزيادة.
- يمكن رفع عدد الجولات بعد انتهاء الخطة وتشغيل الجولة التالية. الموجّه يتغيّر كل جولة (حسب ترتيب الانضمام داخل الفريق).
- كل فريق في غرفة صوتية منفصلة (Zoom/Teams breakout). الموجّه يتكلم، البنّاؤون يسمعون ويسألون.
- أفضل حجم فريق: ٣–٥ لاعبين.

## النقاط (لكل فريق، ويتشاركها أعضاؤه)
قطعة صحيحة +١٠ · محاولة خاطئة −٥ · إكمال +٥٠ · سرعة حتى +٥٠ (تقل خطيًا مع زمن البناء).
الحد الأقصى: جولة ١ = ١٩٠ · جولة ٢ = ٢٢٠ · جولة ٣ = ٢٦٠ → المجموع ٦٧٠ (للثلاث). الجولات الأولى هي الأصغر، فخطة جولة أو جولتين تبدأ بالرادار ثم محرك النمو.
الترتيب: النقاط ثم أقل زمن إجمالي. زمن الجولات يعتمد على ساعة وسيط ntfy (يُقدَّر عند الإرسال) لتقليل أثر اختلاف ساعات الأجهزة.

## ما تم اختباره
متصفح آلي (Playwright) مع وسيط ntfy مقلَّد: انضمام فريقين، توزيع الأدوار والقطع، الرؤية والإشارات، المحاولة الخاطئة والقفل، إكمال الجولة وحساب النقاط، تدوير الموجّه، الترتيب، البروجكتر، العربية RTL، الاستئناف بعد refresh، التدريب الفردي، تخزين محجوب. ٣١ فحصًا ناجحًا + ١١ فحصًا لاختيار عدد الجولات والبدء الفوري. لقطات بالحركة لشاشات الموجّه والبنّاء والنتيجة والمدرب وجوال عربي.

## حدود صريحة
- **لم يُختبر**: ntfy.sh الحقيقي، أجهزة حقيقية، الصوت والموسيقى (مولّدة بالكود ولم تُسمع)، المسار الاحتياطي بالـ polling في هذه اللعبة تحديدًا، جولتان ٢ و٣ حتى النهاية، شاشة البروجكتر أثناء الحركة.
- ntfy.sh المجاني يحدّ نحو ٣٠ اتصالًا حيًا لكل IP. اللعبة تفتح اتصالًا لكل لاعب من لحظة الانضمام، فمجموعة أكبر من ~٢٥ لاعبًا على شبكة واحدة تحتاج وسيط ntfy خاص: أضف `?relay=https://your-ntfy` للرابط.
- الوسيط عام والأكواد قابلة للتخمين: لا تستخدم بيانات سرية. الـ PIN ليس حماية.
- القطع والمخطط موجودة داخل الكود، فمن يفحص المصدر يستطيع رؤية الحل.
- لاعب ينضم بعد توزيع القطع يكون مراقبًا حتى يضغط المدرب RE-DEAL.

## قائمة اختبار على جهازين
1. المدرب على جهاز واللاعبون على جهازين مختلفين (واحد جوال).
2. تأكد من ظهور LIVE عند الجميع وانضمام اللاعبين في لوحة المدرب.
3. START ROUND: يظهر دور كل لاعب، والموجّه وحده يرى المخطط.
4. ضع قطعة من جهاز: تظهر عند الموجّه والفريق خلال ثوانٍ.
5. أكمل جولة: تظهر المنظومة متحركة، ويظهر الفريق ✅ عند المدرب.
6. جرّب Reveal ثم Hide، وReset (كود جديد).
